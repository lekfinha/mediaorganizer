# MediaOrganizer - System & Development Requirements

## System Dependencies (Linux)

### Arch Linux (pacman)
```bash
sudo pacman -Syu \
    webkit2gtk-4.1 \
    gst-plugins-base \
    gst-plugins-good \
    gst-plugins-bad \
    gst-plugins-ugly \
    gst-libav \
    libxml2 \
    openssl
```

### Debian / Ubuntu (apt)
```bash
sudo apt-get update && sudo apt-get install -y \
    libwebkit2gtk-4.1-dev \
    build-essential \
    curl \
    wget \
    file \
    libxdo-dev \
    libssl-dev \
    libayatana-appindicator3-dev \
    librsvg2-dev \
    gstreamer1.0-plugins-base \
    gstreamer1.0-plugins-good \
    gstreamer1.0-plugins-bad \
    gstreamer1.0-plugins-ugly \
    gstreamer1.0-libav \
    gstreamer1.0-tools
```

## Language Toolchains
- Node.js >= 18.x (npm >= 9.x)
- Rust (stable toolchain) >= 1.75.0
